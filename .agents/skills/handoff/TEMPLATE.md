# Handoff template

- Work item and authoritative source: issue/PR URL or actual local draft path.
- Current stage and next stage: named owner, concrete bounded task, entry point.
- Specification revision: accepted artifact identity, decisions and gate record.
- Candidate identity: base and HEAD plus working-tree diff/untracked digest or
  immutable snapshot; local modifications must not disappear from the identity.
- Criteria covered: criterion → independent expected outcome → observed evidence.
- Checks observed: exact command, environment, result and evidence artifact;
  distinguish static/render results from live observations.
- Findings: standards, spec mismatch, operational judgment, responsible stage.
- Unproven claims: skipped/blocked checks, unavailable environment, outstanding
  independent review, unresolved decisions or human approval.
- Suggested skills and agent entry points; required context and access limits.
- Next action: what must happen and what later edits invalidate.

Reference primary sources. The receiver verifies identity before using evidence;
a handoff does not grant permission or let an agent self-approve a human gate.
