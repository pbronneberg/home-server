# Design it twice

For a consequential interface, write constraints, consumers, dependencies, and
failure behavior. Compare at least two meaningfully different shapes: for
example minimal caller knowledge versus an explicit extensibility interface.
Each proposal includes an interface sketch, caller example, hidden complexity,
dependency strategy, and tradeoffs. Use bounded independent agents when supported
and allowed, otherwise compare sequentially and disclose that limitation.
Recommend the option with clearer behavior, justified seams, and concentrated
change. Human architectural choices return to specification and the applicable
gate; a design comparison does not authorize implementation by itself.
